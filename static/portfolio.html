项目起源（面试可照此说）

起初是给自己做的弹道辅助：玩游戏时用地图坐标算迫击炮和 SPH 的 RNG/MIL，少浪费首发弹药。用着用着发现身边新手和散排队友不会从坐标变成炮镜读数， 于是把工具整理成 Web 形态，计划开源，方便大家复制坐标就能完成第一发装填。

非官方项目，与 BULKHEAD / WARDOGS 无关；尊重并参考社区已有计算器与射表贡献者。

背景与痛点

间接火力依赖坐标、方位角、左刻度 RNG 与右刻度 MIL（成对设置）。熟练玩家可用地图计算器； 新手常只调距离不调 MIL、或首发瞎打。FireMind 专注 「第一发怎么设」，试射后的微调交给游戏内肉眼观察（更符合真实习惯）。

产品定位

粘贴或填写炮位 / 目标坐标 → 输出方位角、RNG+MIL 成对读数、队频口令与副官说明（规则引擎，LLM 可选）。 轻量、无需战术地图点选，适合单屏或手机边玩边看。

原理与数据来源

  • 几何：社区标定 1 坐标单位 = 100m 水平距；方位角 atan2(ΔX,ΔY)，0° 北。
  • 射表：L81 / SPH-2 的「距离–MIL」为 Beta 期间社区实测曲线，引擎内线性插值；非官方解包、非封闭弹道公式。
  • RNG：平地上左刻度瞄距 ≈ 地图水平距离，与 MIL 成对使用（两数不必相等）。
  • 地图：MVP 未嵌入游戏贴图/实时地形；V2 可接社区 Terrain3D 思路。
  • AI：仅生成操作说明；不算弹道，避免 LLM 幻觉。

为什么需要 AI（与规则引擎分工）

  • 规则引擎：弹道射表、插值、方位/距离 — 必须确定、可验证，不适合交给 LLM 幻觉。
  • LLM 层（可选）：模糊指令理解、多轮补全坐标、生成口语化回复。
坐标表单 → [规则弹道引擎] → RNG/MIL + 方位角 + 口令 ↓ [可选 LLM] 副官操作说明（不参与数值）

MVP 范围与指标（可面试展开）

  • 范围：L81 + SPH-2；RNG/MIL 成对输出；开源 Web 部署。
  • 北极星：拿到坐标 → 正确设炮（首装填）的完成率。
  • 开源动机：降低新手使用迫击炮 / 攀枝花的门槛，与社区共建射表校验。
